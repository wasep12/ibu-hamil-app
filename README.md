# Aplikasi Perkembangan Kehamilan

Aplikasi ini dirancang untuk membantu ibu hamil dalam memantau usia kehamilan dan perkembangan janin mereka, serta memberikan informasi terkait setiap trimester kehamilan. Aplikasi ini juga menyertakan video edukasi yang relevan pada setiap tahap kehamilan.

## Fitur

1. **Perhitungan Usia Kehamilan**: Pengguna dapat memasukkan tanggal HPHT (Hari Pertama Haid Terakhir) untuk menghitung usia kehamilan dalam minggu dan hari.
2. **Perkiraan Tanggal Lahir (HPL)**: Aplikasi akan menghitung dan menampilkan perkiraan tanggal lahir berdasarkan tanggal HPHT.
3. **Notifikasi HPL**: Aplikasi akan memberikan notifikasi jika HPL telah disimpan.
4. **Perkembangan Janin**: Berdasarkan usia kehamilan, aplikasi akan memberikan informasi mengenai perkembangan janin yang sesuai dengan usia kehamilan.
5. **Video Edukasi**: Setiap trimester dilengkapi dengan video edukasi terkait kehamilan untuk memberikan informasi tambahan bagi ibu hamil.

## Tampilan

Aplikasi ini menampilkan informasi yang dibagi berdasarkan tiga trimester kehamilan:

- **Trimester 1 (0-12 minggu)**
- **Trimester 2 (13-27 minggu)**
- **Trimester 3 (28-40 minggu)**

Setiap trimester dilengkapi dengan video yang dapat diputar untuk mempelajari lebih lanjut tentang perkembangan janin.

## Teknologi

Aplikasi ini dibangun menggunakan teknologi web berikut:

- **HTML**: Struktur dasar halaman web.
- **CSS**: Desain dan styling halaman.
- **JavaScript**: Logika aplikasi untuk perhitungan usia kehamilan, HPL, dan interaksi lainnya.
- **YouTube Embed**: Video edukasi kehamilan yang di-embed dari YouTube.
